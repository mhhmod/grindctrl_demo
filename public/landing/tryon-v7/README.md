# GrindCTRL V7 Try-On Assets

Production-ready visual asset pack for the V7 landing-page try-on experience.

## Structure

- `models/` — full-body model / styled-look images
- `garments/` — standalone garment product images

## Asset handling

- Format: WebP
- Original source dimensions preserved
- High-quality WebP export
- Metadata stripped for predictable web delivery
- Every image was decoded after export before committing
- Git blob SHA was verified against the locally generated file before the commit
